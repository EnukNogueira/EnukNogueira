## Projetos em destaque

### 🔋 NASA Battery — Machine Learning

Projeto de análise da degradação de baterias utilizando dados da NASA.

O projeto envolve tratamento de dados, análise exploratória e aplicação de modelos de Machine Learning para prever a capacidade das baterias ao longo dos ciclos.

**Tecnologias:** Python · Pandas · Scikit-learn · Machine Learning

[Ver projeto](https://github.com/EnukNogueira/nasa-battery)

---

### 🎮 Steam — Análise de Dados

Projeto de análise de dados utilizando um dataset de jogos da Steam.

O projeto começou com o tratamento e a limpeza dos dados e evoluiu para análises sobre preços, avaliações, gêneros e publishers.

Atualmente estou revisando as análises e desenvolvendo um dashboard no Power BI.

**Tecnologias:** Python · Pandas · Matplotlib · Power BI

[Ver projeto](https://github.com/EnukNogueira/analise-steam)

---

### ⚙️ Omni Finance Engine

Sistema financeiro desenvolvido em Java para praticar orientação a objetos, regras de negócio, persistência de dados e integração com APIs.
